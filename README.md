# Balloon

2D-сатира: не дать шарику упасть на землю. У шарика лицо с эмоциями по высоте, шариков всего три

Godot 4.4. Проект Godot лежит в `balloon/`: открыть `balloon/project.godot` в редакторе, запуск F5.
